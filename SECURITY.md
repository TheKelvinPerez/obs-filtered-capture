# Reporting a security issue

Use GitHub's private vulnerability reporting feature for suspected exposure of excluded content or another security issue. Do not attach private screen recordings, credentials or application content to public issues.

Include plugin, macOS and OBS versions, reproduction steps using disposable content, and whether the issue occurs during steady capture or an app relaunch, display reconnect or wake.

This beta has asynchronous app lifecycle refresh and does not guarantee protection of every transition frame. Exclusions apply only to this source. There is no committed security response SLA.
